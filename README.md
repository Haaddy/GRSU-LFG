# Функциональные требования
- реализовать Авторизацию пользователя
- возможность просмотра профиля и статистики
- DashBoard мероприятий
- возможность создать мероприятие
  - название мероприятия
  - описание
  - количество участников/команд
  - на мероприятии нужны команды или же ненужны
    - елси нужны указываем максимальное и минимальное число участников в команде
  - период проведения
  - теги (опционально)   
- возможность присоеденится\записатся на мероприятия (комнды действуйю в рамках конкретного мероприятия)
  - если мероприятие не требует команд то просто запись
  - если требует то создание команды с указанием названия текстом описания (ищу лдей в команду)
  возможность пригласить друзей в команду
  - возможность запросить вступление в команду
     
- фильтрация мероприятий(завершённые все предстоящие по периоду или тегам)
- возможность покинуть мероприятие
